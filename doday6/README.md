# DoDay6 영어 관리 점검 (광고 유입용 설문)

광고를 보고 들어온 원장님이 점검에 답하면 → 맞춤 진단 리포트가 뜨고 → 마지막에 무료 체험을 신청하는 한 페이지입니다.
응답은 구글 시트에 쌓입니다.

| 파일 | 역할 |
|---|---|
| `index.html` | 설문 페이지 (깃허브 페이지에 그대로 올림) |
| `apps-script/Code.gs` | 구글 시트에 저장하는 스크립트 |

---

## 1. 구글 시트 연결 (10분)

1. 구글 시트를 새로 만듭니다. 이름 예: `DoDay6 점검 응답`
2. 메뉴 **확장 프로그램 → Apps Script**를 엽니다.
3. `Code.gs` 내용을 지우고 `apps-script/Code.gs`를 통째로 붙여 넣은 뒤 저장합니다.
4. 오른쪽 위 **배포 → 새 배포**를 누릅니다.
   - 유형: **웹 앱**
   - 실행 사용자: **나**
   - 액세스 권한: **모든 사용자**
5. 권한 허용을 마치면 나오는 **웹 앱 URL** (`https://script.google.com/macros/s/.../exec`)을 복사합니다.
6. `index.html`의 `CONFIG`에 붙여 넣습니다.

```js
const CONFIG = {
  SHEET_URL: "https://script.google.com/macros/s/.../exec",
  KAKAO_URL: "https://pf.kakao.com/_xxxxx/chat",
  ...
};
```

> 스크립트를 고친 뒤에는 **배포 → 배포 관리 → 수정 → 새 버전**으로 다시 배포해야 반영됩니다.

## 2. 올리기 전에 채울 설정

| 항목 | 설명 |
|---|---|
| `SHEET_URL` | 위 5번 주소. 비어 있으면 신청이 저장되지 않고 카톡 버튼만 보입니다 |
| `KAKAO_URL` | 카카오톡 채널 채팅 주소. 비어 있으면 카톡 버튼이 숨겨집니다 |
| `PRIVACY_URL` | 개인정보 처리방침 주소 |
| `RETENTION` | 개인정보 보유 기간. **처리방침에 적힌 기간과 같게** 적어주세요 |
| `TOTAL_SEATS` / `TRIAL` / `CALL_DAYS` | 선착순 자리 수 / 체험 기간 / 연락 기한 |

## 3. 시트에 쌓이는 것

한 원장님 = 한 줄입니다. 단계는 아래 순서로만 올라갑니다.

| 단계 | 뜻 |
|---|---|
| `report` | 리포트까지 봤지만 번호는 남기지 않음 |
| `lead` | 리포트 받을 번호를 남김 |
| `applied` | 체험 신청까지 함 (`대기`가 "예"면 자리가 찬 뒤 대기 신청) |

광고 주소에 `?utm_source=instagram&utm_campaign=pilot1`처럼 붙이면 어느 광고로 들어왔는지 같이 저장됩니다.
'남은 자리'는 시트의 `applied` 수(대기 제외)로 계산합니다. 시트를 읽지 못하면 남은 자리는 표시하지 않습니다.

## 4. 파일럿 우선순위 점수 (시트의 `점수`, `등급`)

화면에는 보이지 않고 시트에만 저장됩니다. 최대 24점.

| 항목 | 점수 |
|---|---|
| 재원생 | 31~100명 3 · 30명 이하/101~150명 1 · 151명 이상 0 |
| 선생님 수 | 원장님 혼자 3 · 2~3명 2 · 4명 이상 0 |
| 결정 | 제가 직접 3 · 선생님들과 의견 나눠 2 · 대표·본사와 함께 0 |
| 도입 시기 | 지금 바로 3 · 올해 안 2 · 신학기 전 1 · 둘러보는 중 0 |
| 관리 방식 | 새 방식을 찾는 중/바꾸고 싶은 부분 있음 2 · 손이 많이 감 1 · 대체로 괜찮음/그대로가 좋음 0 |
| 무료 체험 의향 | 바로 써보고 싶음/지금 쓰는 것과 비교하고 싶음 2 · 먼저 보고 정함 1 · 지금은 괜찮음 0 |
| 불편 신호 | 학부모 소통이 자동이 아님 +1 · 채점 하루 1시간 이상 +1 · 숙제 못 해 옴 2명 이상 +1 |
| 걱정 | "특별히 없어요" +1 |
| 행동 | 번호 남김 +1 · 체험 신청 +3 |

- **A (16점 이상)**: 우선 연락
- **B (11~15점)**: 2순위
- **C (10점 이하)**: 대기 또는 정기 소식

기준을 바꾸려면 `index.html`의 `SCORE`와 `pilotScore()`를 고치면 됩니다.

## 5. 올린 뒤 확인

- [ ] 로그인하지 않은 폰(시크릿 창)으로 끝까지 해보고, 시트에 한 줄이 생기는지
- [ ] 체험 신청 후 그 줄이 `applied`로 바뀌는지 (새 줄이 생기면 안 됨)
- [ ] 카톡 버튼과 개인정보 처리방침 링크가 열리는지
- [ ] 남은 자리 숫자가 시트의 신청 수와 맞는지
